编排

封面与预告

Brief 进画布，多 Agent 生成图、视频和文档，节点可拖可连。
Tokens

设计系统随包走

色板、字体与组件约定写入 Handoff，交给 Cursor 继续写。
Export

一键导出开发包

PNG、Prompts、Token、Brief 一并打包，不编造指标。

这一类还没有精选作品。可以换筛选，或直接写 Brief 进画布。

Skill

流水线

编排 Orchestrate

把 Brief 拆成多 Agent 流水线，在画布上推进，而不是单次对话猜完全部。

默认开启多 Agent

设计系统 Tokens

色板、字体与组件约定跟作品走，交给 Cursor 时不必再猜视觉规则。

默认开启Token

Handoff Export

导出给 coding agent 的开发包：PNG、prompts、设计 token、完整上下文。

默认开启导出
七个 Agent

架构师 Architect

把 Brief 收成结构与范围，后面的 Agent 按同一份边界干活。

结构

设计方向 Director

定视觉气质与禁区，避免后面各步各自发明一套风格。

方向

布局工程师 Layout

在无限画布上排几何与层级，产出可落地的构图，不是线框示意。

构图

文案 Content

写标题、正文和按钮。开源项目只陈述事实，不编指标。

文案

图片规划 Planner

列出要生成的槽位与提示词，执行步按清单落图，而不是随机出图。

规划

图片执行 Executor

按规划生成成品视觉，直接放到作品板，不产出 HTML mock。

生成

审查员 Critic

对照 Brief 做质量审查与修复建议，导出前把缺口补上。

审查

没有匹配的 Skill。试试「编排」「Handoff」或某个 Agent 名称。

设置

通用

语言

界面文案语言。当前原型以简体中文交付。

主题

工作台底色。默认浅色，与创作首页一致。

精简侧栏

收成图标轨，画布区更宽。也可点侧栏顶部按钮。

减少动效

关闭侧栏开合与卡片抬升。系统「减少动态效果」开启时会自动遵循。
