# Canvas 作品板设计（A+B+C）

定调：画布 = 作品画廊。A 稳定、B 展示、C 创作流嵌进壳内。

## 节奏

1. P0 镜头主权 / 选中订阅 / 清 debug / 浮动条避让与主操作收敛
2. P1 卡片极简 / 空态 / 生成微动效 / 失败叠层
3. P2 设为参考 → Composer / 多选批量

## Wave 1–3（一体感 / 安静 / 变体）

- 选中图：Composer 占位「针对这张」；chip「针对 · …」
- 选中旁迷你输入：直接 `onRunPrompt` 发送
- 主操作 `×2` / `×4` 变体网格请求
- 浏览态：工具条/小地图/缩放默认淡化，hover 显现；非选中图降透明度

## 成功标准

- 默认只见图，状态与工具选中/hover 才露
- 生成不抢镜头；仅首张 / 用户聚焦 / 适配按钮才 zoom
- 选中条贴边不裁切；主操作 ≤3
- 选中即可聊、可一键变体，少扭头打字
