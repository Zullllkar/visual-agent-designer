# 画布选中图右侧「+」派生空节点

**日期：** 2026-08-12  
**状态：** 已批准，进入实现

## 目标

选中一张已有 `image-asset` 时，在节点右侧显示圆形 `+`；点击后创建带血缘的空子节点，并将源图推入右侧 Composer 参考 chip 并聚焦输入框。生成仍走聊天 Agent。

## 决策

| 项 | 选择 |
|----|------|
| 入口 | 源图右侧圆钮 `+`（仅单选、非空占位） |
| 生成 | 聊天 Agent（不新建底部生图面板） |
| Composer | `offerComposerRef(源图)` + `requestComposerFocus()` |
| 实现 | 选中态叠 `+`，复用 `parentAssetId` + `asset-link` |
| 本期不做 | 浮动条重复入口、独立空图 shape 类型、结果强制合并进占位 id（P1） |

## 行为

1. 单选有图资产 → 右侧中部显示 `+`
2. 点击 → upsert 子资产（`parentAssetId`、空 `src`、默认尺寸同父展示比例）→ sync 落点父右 → 连线 → 选中子节点 → Composer 参考 + 聚焦
3. 空子节点不显示 `+`；多选不显示
4. 空节点 UI：图标 +「图片」文案（上传入口可选，本期可仅视觉）

## 验收

- 选中源图可见 `+`；点后出现空子节点与连线
- Composer 出现源图参考 chip 且输入框聚焦
- 空子节点无 `+`；删除子节点行为与现有 discard 一致
